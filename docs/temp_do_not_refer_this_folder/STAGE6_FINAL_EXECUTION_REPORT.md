문제: MACE 모델의 TorchScript 변환 실패

근본 원인:
  • MACE는 e3nn (Euclidean Neural Networks) 라이브러리 사용
  • e3nn의 동적 텐서 연산이 정적 TorchScript 그래프로 변환 불가
  • 이는 알려진 커뮤니티 이슈이며 상위 라이브러리 수정 필요

에러 메시지:
  RuntimeError: 'Tuple[int, int]' object has no 
  attribute or method 'dim'

시도한 해결 방법:
  1. torch.jit.script() → 실패
  2. torch.jit.trace() → 실패 (입력 형식 불일치)
  3. 예제 입력 조정 → 실패
  4. 모델 추출 및 재시도 → 실패

결론: 현재 기술 스택으로는 순수 C++ LibTorch 구현 불가능
